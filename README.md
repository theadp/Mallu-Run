# 🥥 Mallu Run: Escape the Monsoon

**Created by Adeeb Pulath**

A retro pixel-art runner inspired by the Kerala monsoon.
Run, jump, dodge obstacles, collect coins, and survive the escalating rain before the flood takes over! 🌧️🌊

## 🎮 Play the Game

**Live Demo:** https://theadp.github.io/Mallu-Run/
              https://mallu-run.vercel.app/

## 🕹️ Gameplay

Mallu Run features **3 levels**, with the weather and difficulty increasing as you progress.

### 🌴 Level 1 — Naadu Road

**Difficulty:** Easy

Start your journey on a Kerala road during the beginning of the monsoon.

* Potholes
* Low branches
* Light rain
* Coin collection

### 🌧️ Level 2 — Monsoon Madness

**Difficulty:** Medium

The rain gets heavier and the road becomes more dangerous.

* Increased difficulty
* Heavy rain
* More challenging obstacles
* Coin collection

### 🌊 Level 3 — Flood Escape

**Difficulty:** Climax

The monsoon reaches its peak.

Survive the flooding and make your escape!

## 🎮 Controls

### 🖥️ Desktop

| Key       | Action     |
| --------- | ---------- |
| **A / ←** | Move Left  |
| **D / →** | Move Right |
| **Space** | Jump       |
| **S / ↓** | Slide      |

### 📱 Mobile

Use the on-screen touch controls for movement, jumping, and sliding.


## ❤️ Objective

Survive all three levels while avoiding obstacles and collecting coins.

You have **3 lives**. Use them wisely!
